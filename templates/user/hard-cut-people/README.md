# 硬切人

人物与场景插画风格模板。核心特征是**低多边形人物**与**清晰的硬边切面**：用几何平面塑造人物，让轮廓、体块和切面边界清楚可见。配色按每次主题自由选择。

## 参考图

![硬切人参考图：两位身穿深灰西装的人物在暖米白背景前交接文件，画面左侧留白](reference.png)

风格名称由用户指定；本目录保留用户提供的原始参考图，作为低多边形人物造型与硬边切面的视觉依据。

## 视觉定义

| 维度 | 模板规则 |
| --- | --- |
| 人物造型 | 成人真实比例，轮廓清楚；头发、面部、衣服与肢体由大小适中的三角形或多边形切面构成。 |
| 切面质感 | 相邻平面有明确的色块与明暗差异，边界利落；整体仍保留体积感，不添加粗描边。 |
| 面部处理 | 简化五官，保留朝向与头部结构；主要通过姿态、手势和人物距离传达关系。 |
| 配色 | 按当前主题、品牌或页面需要自由选择人物、服装与背景颜色。 |
| 光影 | 用色块或明暗差异突出几何体块，保持相邻切面的边界清楚；光照方式随场景选择。 |
| 动作与道具 | 每幅图围绕一个可辨认的动作，只保留解释该动作所需的道具；手部与道具的接触关系应自然。 |
| 构图 | 按页面选择画幅、主体位置与留白；需要配文时预留文字空间，重要手势与道具保持完整。 |
| 文字 | 图片中不生成标题、字母、数字、标志或水印；标题、正文和标注在 PPT 中另行添加，保持可编辑。 |

## 可复用提示词

将方括号中的内容替换为当前页面的需求：

```text
使用「硬切人」风格，创作一幅 16:9 横向演示文稿插画。

画面要让观众在三秒内理解：[本页要表达的关系或结果]。
主体为 [人数与角色]，正在 [一个明确的动作]，必要道具是 [道具及其用途]。

人物采用接近真实的成人比例，以清晰的三角形和多边形硬切面构成头发、面部、衣服与肢体。
面部简化，保留朝向与结构；通过姿态和手势说明人物关系。切面边界利落，有克制的明暗差异与体积感，无粗描边。
人物、服装与背景采用 [本次主题需要的配色，或自由选择]；光影应使几何体块与切面边界清楚可见。
按 [本页构图需求] 安排主体与背景，需要配文时在 [位置及所需比例] 留出文字空间。
确保关键手势、人物关系和道具完整可见，手部接触自然。

不要生成文字、字母、数字、标志、水印或假文字。避免圆润玩具感、夸张卡通比例、光亮塑料皮肤、密集碎面和复杂背景。
```

## 参考场景示例

> 使用「硬切人」风格，表现项目成果交接：两位穿西装的项目成员相向站立，一方递出无字的成果文件夹，另一方用双手接住。人物集中在画面右侧，左侧约 40% 留白。采用低多边形人物造型、成人比例与简化五官，相邻几何平面之间有清晰的硬边切面，色块或明暗差异呈现体积感。配色自由选择。16:9 横幅，手势和文件夹完整可见，图片内无文字、标志或水印。

复用时可替换人数、职业、服装、动作、道具、配色与构图，例如围桌讨论方案、指向流程中的问题、检查交付清单。持续保留低多边形人物和清晰硬边切面这两个核心特征。

## 使用检查

- 人物由可辨认的多边形平面构成，切面边界清晰利落，保留体积感。
- 不看标题也能辨认正在发生的动作，人物数量、姿势与道具符合页面意思。
- 关键手势与道具未被裁切，需要配文时有足够的文字空间。
- 背景干净，图片内没有文字、标志、水印或多余装饰。
