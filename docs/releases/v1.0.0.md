# PPT-Ops V1.0.0 Release Notes

Status: release candidate; GA has not been published.

V1.0.0 delivers a Codex-native, local-first PPT Agent that turns a topic, Markdown, DOCX, or existing PPTX into traceable PageSpecs and editable PowerPoint output. It includes deterministic candidate approval, immutable versions and builds, eight semantic templates, HTML/PPTX rendering, safe source intake, Review evidence, handoff packaging, Doctor/reindex recovery, and guarded updates.

The GA release workflow remains locked until the machine-readable acceptance matrix contains evidence for human visual review, manual Microsoft PowerPoint interaction, Chrome and Safari HTML artifact checks, delivery-package verification, and three independent target-user trials completed without code changes.

Known boundaries:

- Codex conversation through `$ppt-agent` is the product interface; there is no Web Workbench.
- HTML is an optional output artifact.
- Automated rendering and structural checks do not replace human visual or real PowerPoint acceptance.
- Existing PPTX files are imported as traceable sources; arbitrary round-trip preservation is not promised.
- Fonts can substitute on machines where the selected fonts are unavailable.
