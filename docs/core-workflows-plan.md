# PPT-Ops 三个功能入口规划

> 更新日期：2026-09-11
>
> 状态：需求规划；本文不代表三个入口均已实现或验收。
>
> 当前范围：资料生成 PPT、结构生成 PPT、已有 PPT 的视觉润色。文字润色和结构优化列入后续规划。

## 1. 功能入口

| 入口 | 用户提供 | 主要流程 | 交付结果 |
|---|---|---|---|
| 资料生成 PPT | 文稿、文档、图片、音频、视频、网页等任意类型材料，可单独或混合提供 | 理解材料 → 提炼主线 → 输出章节与逐页结构 → 用户确认结构 → 页面设计与生成 | 可编辑 PPTX 与预览 |
| 结构生成 PPT | 章节大纲或逐页安排 | 沿用已有结构 → 必要时拆页 → 页面设计与生成 | 可编辑 PPTX 与预览 |
| 已有 PPT 视觉润色 | PPTX 文件、目标页面与视觉要求 | 查看原页 → 定位视觉问题 → 制作关键页对照 → 应用视觉修改 → 检查交付 | 润色后的可编辑 PPTX、修改前后对照与修改记录 |

三个入口按用户已有材料进入对应阶段。资料可以完整、零散、单份或多份，用户可以直接提供原始材料。页数、时长和风格等信息已在材料或当前对话中明确时，直接沿用。

## 2. 资料生成 PPT

### 2.1 输入材料

入口按材料内容组织流程，材料类型保持开放。以下为常见示例，可分别使用，也可混合使用：

| 材料 | 理解与提取重点 | 来源定位 |
|---|---|---|
| 文字与文档 | 逐字稿、文章、笔记、PDF、Word 等中的观点、事实与信息关系 | 文件、页码或段落 |
| 图片 | 照片、截图、扫描件、图表中的文字、画面内容与视觉关系 | 图片文件及对应区域 |
| 音频 | 录音、访谈、课程中的讲述内容、主题与关键片段 | 文件与时间段 |
| 视频 | 结合声音、字幕、关键画面和演示过程理解内容；无声视频也可作为资料 | 文件、时间段与关键帧 |
| 网页及其他材料 | 提取可读取的内容与关联素材，按实际类型选择理解方式 | 原始链接或文件内位置 |

图片、音频和视频可以直接作为主要内容来源；材料理解、必要的文字识别、转写与关键画面提取由系统承担，用户无需先整理成完整逐字稿。视频理解应同时关注画面与讲述，图片中的非文字信息也应进入结构判断。

### 2.2 处理流程

```text
提供单份或混合材料
  → 识别材料类型与用途
  → 理解文字、画面、声音及其关系
  → 汇总主题、事实、可用素材与待核实项
  → 输出章节与逐页结构
  → 用户确认结构
  → 页面设计与 PPT 生成
```

先给出可审阅的结构，再生成 PPT。结构至少包含章节顺序、逐页主题、核心观点和对应材料来源；将上屏内容与适合口述的内容分开。用户已说明材料用途时，沿用其指定的内容来源、视觉参考或直接使用素材等角色。

混合材料中重复的信息应合并，互相矛盾或识别不清的内容应标记待核实。材料缺口影响结论时，列出具体缺口，不补造事实；无法读取的文件或片段需明确记录，不能视为已理解。

用户确认结构后，进入关键页视觉设计和整套生成。用户对结构的修改应落实到逐页安排，避免生成阶段重新改变已确定的主线。页面内容压缩必须保留原意，不补造案例、数据或结论。

### 2.3 验收重点

- 文字、图片、音频、视频和混合材料分别有独立案例；仅图片或仅视频也能进入结构生成流程。
- 理解结果涵盖材料中与主题相关的画面、讲述和信息关系；未读取或无法确认的内容明确标记。
- 每页可追溯到原始材料的页码、区域、段落或时间段。
- 生成稿与确认后的结构一致；PPTX 可编辑并通过实际播放检查。

## 3. 结构生成 PPT

支持两种输入粒度：

- **章节大纲**：保持章节和主线，补充逐页安排后进入制作。
- **逐页结构**：沿用页序与每页任务，直接进入页面设计和生成。

“直接生成”指从已有结构继续，不重复执行从原始材料提炼大纲的步骤。若缺少决定页面内容的事实或素材，标记具体缺口并收集必要信息，不以虚构内容填满页面。

验收重点：已有结构得到保留；章节大纲能转为明确的逐页任务；最终稿可编辑、可预览。

## 4. 已有 PPT 视觉润色

### 4.1 本阶段范围

支持整套或指定页面的视觉调整：

- **排版**：对齐、间距、留白、元素位置、尺寸、视觉重心和层级。
- **字体**：字体搭配、字号、字重、行距与可读性。
- **配色**：统一色板、改善对比度、调整背景与强调色。
- **图片**：修正拉伸、比例、裁切、清晰度和图文布局；需要替换时沿用真实素材或已认可的配图方向。
- **图表与形状**：统一线条、填充、标签样式和装饰元素；保留数据、单位、坐标含义及信息关系。
- **整套一致性**：统一标题、正文、页码等样式，并在原有视觉体系内改善页面节奏。

默认保留原文、事实、数字、章节、页序和品牌视觉风格。文字排不下时，优先调整布局与空间，不擅自删改文字或把文字缩到不可读。更换整套风格需以用户明确要求为依据。

### 4.2 使用流程

```text
导入 PPTX 并保留原文件
  → 渲染原页，识别页面元素与原有视觉风格
  → 确定整套或指定页面的修改范围
  → 给出视觉问题与关键页修改前后对照
  → 按已明确的视觉方向应用修改
  → 检查内容保持、目标范围、版面与编辑能力
  → 在 PowerPoint 中打开、编辑和播放检查
  → 交付独立的润色文件、对照预览与修改记录
```

用户已明确指定的视觉调整可以直接执行；对照样张用于让视觉方向可审阅，不要求重复确认已授权的调整。

### 4.3 文件处理边界

该入口需要读取原 PPT 的页面元素并在原有演示文稿基础上修改。仅提取文字后重新生成整套 PPT，不能作为保留原稿视觉润色的实现证据。

首批实现以原生文字、图片、基础形状和可支持的图表样式为范围，保留原文件和未修改页面。遇到无法安全编辑的动画、SmartArt、嵌入对象等元素时，应保留并列出具体限制，不静默删除或把整页栅格化；确需重建时再明确重建范围。任意 PPTX 的所有特性无损往返仍不作承诺。

### 4.4 验收标准

- 润色前后的文字、事实、数字、图表数据和页序一致。
- 只修改指定页面及授权的视觉属性；未指定页面的内容和呈现保持不变。
- 原有品牌元素与风格得到保留，除非用户要求更换。
- 目标页面有修改前后对照，可说明每项修改解决了什么视觉问题。
- 实际渲染中无文字截断、意外重叠、图片拉伸或不可读的字号与对比度。
- 原生文字和所支持的对象仍可编辑，不以整页图片替代可编辑交付。
- 在 Microsoft PowerPoint 中完成打开、目标对象编辑和播放检查；自动结构检查与实机验收分别记录。

## 5. 后续规划

| 后续功能 | 计划处理内容 | 启动条件 |
|---|---|---|
| 文字润色 | 标题与措辞优化、表达精简、术语统一、口述与上屏内容分配 | 视觉润色闭环完成后，单独明确允许改写的内容范围 |
| 结构优化 | 主线与衔接诊断、顺序调整、合并拆分页、逻辑缺口提示 | 后续单独定义结构修改范围与验收标准 |

以上两项不进入当前视觉润色入口的默认流程。现有内容审查可以继续作为独立能力使用；生成入口必要的内容提炼与拆页也保持原有职责。

## 6. 实现状态与后续交付

现有系统已具备资料导入、结构化页面、HTML/PPTX 生成和检查等基础能力。图片、音频、视频作为主要内容来源的理解与结构生成闭环仍需按材料类型实现和验收，已有配图能力不能代替这些验收。旧 PPTX 当前可作为内容真源提取；保留原有页面元素进行视觉润色的完整闭环仍需实现和验收。

后续实现应分别完成：

1. 三个入口的任务识别与阶段衔接。
2. 资料理解、来源定位与混合材料整合，以及资料生成和结构生成两条路径的独立验收。
3. 原 PPT 元素读取、限定视觉属性修改、未修改页面保留及对照预览。
4. 使用真实 PPT 完成视觉润色、可编辑性和 PowerPoint 实机验收。

本次只更新功能规划，不变更运行代码、数据契约或现有验收结论。产品范围同时见[产品备案](product-v1.0-blueprint.md)；现有 CLI 验收边界见[V1.0 Requirements](requirements-v1.0.md)。
