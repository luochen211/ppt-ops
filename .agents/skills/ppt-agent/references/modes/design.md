# Design Mode

Use the accepted Outline, profile brand rules, semantic template catalog, `visual-quality.md`, and `visual-assets.md`. Define Theme tokens, opening job, page rhythm, page-template choices, asset needs, and density budgets without changing facts. Always create ImageGen briefs and slots for the canonical first and final page; for a one-page deck one accepted image may own both roles. Define each asset's semantic action before choosing a style preset. Exit with an accepted design direction and explicit boundary-image status. Load Source bodies only when a cited visual decision requires authorization.
