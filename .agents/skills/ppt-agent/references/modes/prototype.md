# Prototype Mode

Build a representative small page set when visual direction is uncertain. Apply `visual-quality.md` and `visual-assets.md`, include different content shapes and rhythm, validate structure, render evidence when available, and request focused feedback. Generated characters or scenes must follow the prepare, ingest, visual-observation, and explicit-decision gates; never register an unaccepted generation. Exit with an accepted direction or explicit changes; never regenerate unselected approved pages.
