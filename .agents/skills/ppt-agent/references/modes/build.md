# Build Mode

Build only from a Frozen Version. Before freezing or rendering, load `visual-assets.md` and verify that the canonical first and final pages each resolve to a pipeline-registered ImageGen asset with passing automated inspection, passing exact-candidate visual observation, and explicit user acceptance. A one-page deck may reuse one accepted image. On failure, stop with the page-addressable evidence gap. Then create native PptxGenJS text, shapes, charts, and tables; HTML is optional output and never an intermediate conversion step. Exit with an immutable Build manifest or a retryable failure record.

Project creation, Outline and Design do not require export-format configuration. Build targets are explicit review artifacts, not implicit delivery choices. Keep the final Handoff choice separate and ask only at that boundary; PDF is derived from an eligible reviewed artifact, not generated from unreviewed mutable content.
